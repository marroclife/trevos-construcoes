# Trevos Construções — Loja de Materiais de Construção

Projeto de e-commerce + site institucional para a **Trevos Construções**, loja de materiais de construção em **Mangaratiba, RJ**.

## Base Técnica
Código iniciado a partir de uma cópia do projeto **Frio Costa Verde** (React + Vite + Tailwind + Prisma + Express API), adaptado para o contexto de materiais de construção.

## Referências de Modelo
- **KingOuro** (`https://www.kingouro.com.br/`) — portal B2B de materiais e ferragens.
- **Nova Boni** (`https://www.boni.com.br/`) — e-commerce de materiais de construção (fornecedor).

## Fase Atual
Mockup de catálogo e estrutura inicial. Preços simulados. Serviços ainda em definição junto com a dona do estabelecimento.

## Comandos
```bash
npm install
npm run dev        # porta 3000
npm run build      # produção
npm run db:seed    # popular dados mock
```
